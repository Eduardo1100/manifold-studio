# Manifold Studio brand alignment

Brand version: `manifold-brand@1.0.0`

Synchronized: `2026-07-27`

This showcase is a downstream Manifold surface. The official
[Manifold brand source](https://manifold-official.eduardo11.chatgpt.site)
defines the canonical mark, favicon, visual tokens, naming, and usage rules.
The local files `manifold-mark.png` and `favicon.png` are byte-for-byte copies
of those approved raster assets; they must not be traced, redrawn, recolored,
or replaced by CSS geometry.

The machine-readable provenance and asset checksums are recorded in
[`brand-provenance.json`](brand-provenance.json). The release workflow verifies
both canonical asset hashes before staging an explicit allowlist for GitHub
Pages.

## Surface profile

Manifold Studio · Idea Search keeps its dense creative-search cockpit:
comparison, judgment, proposed guidance, human decisions, regeneration, and
trace remain its information architecture. Brand alignment changes its shared
identity—not its evidence boundary or product claims.

- Shell: deep Manifold ink tones with restrained midnight borders.
- Ambient light: cyan and ember only.
- Actions: dark luminous-edge surfaces; no retired blue-violet fill.
- Violet: not used decoratively or as a general action color.
- Body and interface type: system sans; evidence and fingerprints: system mono;
  human judgment only: Iowan/Georgia serif.
- Accessibility: cyan focus rings, reduced-motion support, explicit active-stage
  semantics, and horizontally scrollable dense tables on narrow screens.

## Version policy

The `brand_version` changes only when the official Manifold brand release
changes. Any checksum change to either canonical asset requires a new upstream
brand release and an intentional downstream synchronization.
