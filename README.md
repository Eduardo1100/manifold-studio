# Manifold Studio — Idea Search

**Idea Search** is the Manifold Studio feature for choosing creative direction
with a person in the loop:

    Manifold
      Manifold Studio
        Idea Search

Compare prompt candidates, explain what works, and decide what carries into the
next round. The model drafts prompts. You decide what carries forward: only
accepted guidance is injected into later generation, and the provenance chain
from judgment to accepted item is preserved.

This repository contains the static, evidence-backed showcase for that feature.

Idea Search is the Manifold Studio presentation of the system originally
developed as Subjective Skill Studio. The evidence in this bundle was generated
from that system's source snapshot, which predates the Manifold branding.

**Live site:** [https://eduardo1100.github.io/manifold-studio/](https://eduardo1100.github.io/manifold-studio/)

**Manifold:** [https://manifold-official.eduardo11.chatgpt.site](https://manifold-official.eduardo11.chatgpt.site)

## What this is

The application source (FastAPI + SQLite backend, React + Vite + TypeScript
frontend) remains in a **private** repository. This repository publishes only
a static, self-contained walkthrough page, the deterministic evidence it is
built from, and the metadata needed to host that page on GitHub Pages.

## What the walkthrough proves -- and does not

The walkthrough is generated by running the real backend routes and services
in-process (FastAPI `TestClient`) against the project's built-in **mock**
provider, then canonicalizing every id, timestamp, and fingerprint into a
stable token so the output is byte-identical on every regeneration. That
means it demonstrates:

- candidate comparison, natural-language judgment, drafted memory proposals,
  and human accept/edit/reject decisions;
- accepted-memory injection into a regenerated batch, with fingerprints and a
  provenance chain back to the judgment that produced each accepted item.

It does **not** demonstrate content-sensitive proposal quality, generation
quality from a hosted LLM provider, or production usage -- the mock provider
returns fixed text, and this is a product demonstration on synthetic data,
not a benchmark.

See [`evidence/manifest.json`](evidence/manifest.json) for the source
snapshot commit (`82ed65dc01c2`), output file hashes, and which fixture
step supports each claim, and `evidence/fixture/receipts/` for the
human-readable receipts referenced from the page.

## Provenance of this showcase

This showcase presents the pre-participation Subjective Skill Studio system
within the Manifold product family. Its deterministic evidence remains tied to
the audited source snapshot; later Manifold participation features are not
represented here.

## Brand provenance

This surface is synchronized to `manifold-brand@1.0.0`. The local mark and
favicon are exact byte copies of the canonical raster assets; their source
paths, dimensions, and SHA-256 hashes are recorded in
[`brand-provenance.json`](brand-provenance.json). See [BRAND.md](BRAND.md) for
the downstream usage contract and surface-specific profile.
